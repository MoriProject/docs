모든 API 엔드포인트는 `Authorization: Bearer` 헤더의 **API 키**가 필요합니다. [BIZ MORI 대시보드](https://app.bizmori.com/keys)에서 키를 발급해 안전하게 보관하세요. 키는 한 번만 표시됩니다.

<Warning>
  API 키는 계정 접근 권한을 부여합니다. 브라우저 코드, 저장소, 버전 관리에 노출하지 마세요.
</Warning>

## API 키 사용

새 논리 주문마다 UUIDv4를 생성합니다. 아래 예제는 첫 Anti-AI 주문 전에 키를 생성합니다.

<CodeGroup>
```bash cURL
ORDER_IDEMPOTENCY_KEY=$(uuidgen | tr '[:upper:]' '[:lower:]')
curl -X POST https://api.bizmori.com/api/v2/orders/anti-ai \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d "{\"idempotencyKey\": \"$ORDER_IDEMPOTENCY_KEY\", \"files\": [{\"fileName\": \"image.jpg\"}]}"
```

```javascript Node.js
import { randomUUID } from 'node:crypto';

const orderIdempotencyKey = randomUUID();
const response = await fetch('https://api.bizmori.com/api/v2/orders/anti-ai', {
  method: 'POST',
  headers: { Authorization: 'Bearer YOUR_API_TOKEN', 'Content-Type': 'application/json' },
  body: JSON.stringify({ idempotencyKey: orderIdempotencyKey, files: [{ fileName: 'image.jpg' }] }),
});
const data = await response.json();
```

```python Python
import uuid
import requests

order_idempotency_key = str(uuid.uuid4())
response = requests.post(
    'https://api.bizmori.com/api/v2/orders/anti-ai',
    headers={'Authorization': 'Bearer YOUR_API_TOKEN'},
    json={'idempotencyKey': order_idempotency_key, 'files': [{'fileName': 'image.jpg'}]},
)
data = response.json()
```

```php PHP
<?php
$orderIdempotencyKey = sprintf('%04x%04x-%04x-4%03x-%x%03x-%04x%04x%04x', random_int(0, 0xffff), random_int(0, 0xffff), random_int(0, 0xffff), random_int(0, 0x0fff), random_int(8, 11), random_int(0, 0x0fff), random_int(0, 0xffff), random_int(0, 0xffff), random_int(0, 0xffff));
```

```ruby Ruby
require 'securerandom'
order_idempotency_key = SecureRandom.uuid
```

```go Go
import "github.com/google/uuid"

orderIdempotencyKey := uuid.NewString()
```

```java Java
import java.util.UUID;
String orderIdempotencyKey = UUID.randomUUID().toString();
```
</CodeGroup>

## 멱등성

새 논리 주문마다 새 UUIDv4를 사용합니다. Anti-AI와 AI Detection의 confirm은 별도 논리 요청이므로 각각 다른 UUIDv4를 생성합니다. 네트워크 실패 후 같은 논리 요청을 재시도할 때만 이전 값을 재사용하세요. 같은 키를 다시 보내면 새 주문 대신 기존 주문이 반환됩니다.

## Live 및 테스트 API 키

live 키의 `uploadUrl`은 S3 presigned URL입니다. 테스트 키의 URL은 `https://api.bizmori.com/api/v2/test-uploads/{signedToken}` 형식의 절대 BIZ MORI API URL입니다. 두 URL 모두 발급 후 1시간 동안 유효합니다. 업로드와 재발급은 [빠른 시작](/ko/quickstart), 테스트 키 웹훅 범위는 [웹훅](/ko/webhooks)에서 확인하세요.
