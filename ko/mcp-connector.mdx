**ContentCare MCP 커넥터**를 쓰면 Claude 같은 AI 어시스턴트 안에서 바로 ContentCare를 사용할 수 있습니다. ContentCare 계정으로 한 번만 연결해두면, 이후에는 평소 말하듯 요청하면 됩니다.

> "이 이미지가 AI로 생성된 건지 확인해줘: `<이미지 주소>`"

Claude가 ContentCare에서 작업을 실행하고 결과를 대화창에 알려줍니다. 코드도, API 키도, 대시보드도 필요 없습니다.

<Note>
  **MCP**(Model Context Protocol)는 AI 어시스턴트를 외부 서비스와 연결하는 공개
  표준입니다. 사용하는 데 이 개념을 이해할 필요는 없습니다.
</Note>

## 커넥터 연결하기

<Tabs>
  <Tab title="Claude 앱">
    <Steps>
      <Step title="커넥터 설정 열기">
        Claude 앱(웹 또는 데스크톱)에서 **설정 → 커넥터 → 사용자 지정 커넥터 추가**로 이동합니다.
      </Step>
      <Step title="커넥터 URL 입력">
        ```
        https://mcp.contentcare.ai/mcp
        ```

        이름은 알아보기 쉽게 `ContentCare` 정도로 지정하세요.

      </Step>
      <Step title="ContentCare 계정으로 로그인">
        ContentCare 로그인 창이 열립니다. [app.contentcare.ai](https://app.contentcare.ai)에서 쓰는 것과 같은 계정으로 로그인하고 연결을 승인하세요.

        <Check>
          API 키는 **필요하지 않습니다.**
        </Check>

      </Step>
      <Step title="요청해보기">
        새 대화를 열고 이렇게 입력해보세요.

        ```text
        ContentCare로 이 이미지가 AI 생성인지 확인해줘:
        <이미지 주소>
        ```

      </Step>
    </Steps>

  </Tab>
  <Tab title="Claude Code">
    터미널에서 커넥터를 추가합니다.

    ```bash
    claude mcp add --transport http contentcare https://mcp.contentcare.ai/mcp
    ```

    그다음 Claude Code에서 `/mcp`를 실행해 `contentcare`를 고르고, 열리는 브라우저 창에서 ContentCare 계정으로 로그인하세요.

  </Tab>
  <Tab title="Codex CLI">
    커넥터를 추가하고 로그인합니다.

    ```bash
    codex mcp add contentcare --url https://mcp.contentcare.ai/mcp
    codex mcp login contentcare
    ```

    브라우저 창이 열리면 ContentCare 계정으로 로그인하고 연결을 승인하세요.

  </Tab>
</Tabs>

<Note>
  예전에 `https://mcp.bizmori.com/mcp`로 커넥터를 추가했다면, 삭제한 뒤 위의 새
  URL로 다시 추가하세요.
</Note>

## 파일 업로드 방식

**어떤 도구를 쓰느냐에 따라 가능한 파일 업로드 방법이 다릅니다.**

|                                | 대화창에 첨부한 파일 | 내 컴퓨터의 파일 | 파일 주소(URL) |
| ------------------------------ | :------------------: | :--------------: | :------------: |
| **Claude 앱** (웹 / 데스크톱)  |          X           |  ✓ (업로드 창)   |       ✓        |
| **Claude Code** (터미널 / IDE) |          —           |        ✓         |       ✓        |
| **Codex**                      |          —           |        ✓         |       ✓        |

<AccordionGroup>
  <Accordion title="Claude 앱 — 업로드 창이나 파일 주소를 쓰세요" icon="browser">
    대화창에 **첨부한 파일은 사용할 수 없습니다.** 첨부 파일은 Claude가 눈으로 보는 용도로만 들어가고, 커넥터에는 실제 파일이 전달되지 않습니다. ContentCare 쪽에서 해결할 수 없는 플랫폼 한계입니다.

    대신 Claude에게 업로드 창을 열어달라고 하세요.

    ```text
    AI 생성 검사할 이미지를 올릴 수 있게 ContentCare 업로드 창 열어줘.
    ```

    대화 안에 업로드 창이 나타납니다. 파일을 끌어다 놓으면 같은 창에 결과가 표시됩니다. 창이 보이지 않으면 Claude가 대신 10분 동안 쓸 수 있는 일회용 업로드 링크를 줍니다.

    업로드 창은 한 번에 파일 하나를 받습니다. 워터마크 검출만 원본과 검사할 파일, 두 개를 받습니다. 여러 장을 한꺼번에 처리하려면 링크가 생기는 곳 — 링크 공유를 켠 Google Drive, Dropbox, Notion — 에 올린 뒤 링크들이나 ZIP 링크를 대화창에 붙여넣으세요.

  </Accordion>
  <Accordion title="Claude Code — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Claude Code는 파일을 읽을 수 있으므로 파일 위치만 알려주면 됩니다.

    ```text
    ~/Pictures/artwork.png 에 Anti-AI 보호 적용해줘
    ```

    파일 업로드까지 알아서 처리합니다. 파일 주소를 써도 됩니다.

  </Accordion>
  <Accordion title="Codex CLI — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Claude Code와 동일하게 파일 경로만 주면 업로드까지 처리합니다.
  </Accordion>

## 결과 받기

Claude가 작업이 끝날 때까지 기다렸다가 대화창으로 결과를 알려줍니다.

| 서비스            | 받는 결과                                                                         |
| ----------------- | --------------------------------------------------------------------------------- |
| **AI 검사**       | 확률과 판정 결과, 그리고 히트맵·오버레이·썸네일 이미지                            |
| **워터마크 검출** | 내 워터마크가 검출됐는지 여부와, 내가 넣은 워터마크라면 그 문구                   |
| **Anti-AI**       | 보호 처리된 이미지의 다운로드 링크. 여러 장이면 ZIP 하나로 옵니다                 |
| **워터마크 삽입** | 워터마크 문구마다 결과 파일 하나. 여러 개면 ZIP 하나와 파일별 링크가 함께 옵니다 |

모든 결과에는 해당 작업을 [대시보드](https://app.contentcare.ai)에서 열어보는 링크와, 어느 계정으로 청구됐는지가 함께 표시됩니다.

AI 검사는 세 가지 이미지를 기본으로 만듭니다. 추가 비용은 없습니다 — 이미지가 몇 장이든 검사 1회로 계산됩니다. 워터마크 삽입은 문구 하나당 1회로 계산됩니다.

<Warning>
  **오래 걸리는 작업은 "처리 중" 상태로 돌아올 수 있습니다.** Claude는 약 2분까지만 기다리는데, 장수가 많은 Anti-AI나 무거운 워터마크 작업은 그보다 오래 걸릴 수 있습니다.

  실패가 아니라 작업은 계속 진행 중입니다. 결과는 이렇게 받으세요.

  - [대시보드](https://app.contentcare.ai)에서 내려받기. 완료된 작업이 모두 여기 있습니다.
  - 또는 몇 분 뒤 대화창으로 돌아와 Claude에게 그 작업을 다시 확인해달라고 하기.
</Warning>

<Note>
  다운로드 링크는 일정 시간이 지나면 만료됩니다. 링크가 열리지 않으면 Claude에게
  해당 작업의 새 링크를 받거나, 대시보드에서 내려받으세요.
</Note>

### 워터마크 검출에는 원본이 필요합니다

ContentCare는 검사할 파일을 워터마크를 넣었던 원본 파일과 비교해 워터마크를 찾습니다. **Claude에게 항상 두 파일을 함께 주세요.**

결과는 다음 중 하나입니다.

| 결과          | 의미                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| **검출됨**    | 워터마크를 찾았습니다. 내 계정이 넣은 워터마크라면 문구가 표시됩니다.     |
| **검출 안 됨** | 워터마크를 찾지 못했습니다.                                              |
| **판단 불가** | 워터마크 후보는 있지만 확신할 만큼은 아닙니다.                            |
| **처리 불가** | 파일을 처리할 수 없었습니다. 사용량은 복구됩니다.                         |
| **오류**      | 검사에 실패했습니다. 워터마크가 없다는 뜻은 아닙니다. 사용량은 복구됩니다. |

삽입과 검출은 별개의 작업입니다. Claude는 삽입이 잘 됐는지 확인하려고 검출을 스스로 실행하지 않으므로, 두 번 차감되지 않습니다.

### 분석 보고서

워터마크 검출이나 AI 검사 작업이 끝나면 Claude에게 그 작업의 PDF 보고서를 요청하세요.

```text
방금 작업 분석 보고서 한국어로 만들어줘.
```

보고서는 한국어, 영어, 일본어로 받을 수 있습니다. PDF 파일에 대한 보고서는 한국어만 지원합니다. 보고서 링크는 5분 뒤 만료되니, 필요하면 Claude에게 새 링크를 다시 요청하세요.

## 보호해서 내보내기

보호해서 내보내기는 Anti-AI와 받는 곳별 워터마크를 한 번에 적용합니다. 받는 곳 이름이 그대로 워터마크 문구가 됩니다. 나중에 사본이 유출되면 그 사본으로 워터마크 검출을 실행하세요. 검출된 문구로 어느 받는 곳의 배포본인지 알 수 있습니다.

```text
이 이미지들 보호해서 A 스튜디오, B 스튜디오, C 스튜디오용으로 각각 내보내줘:
<이미지 주소 1>
<이미지 주소 2>
```

- **묶음 방식**: 기본은 받는 곳마다 파일 하나입니다. ZIP으로 달라고 하면 이미지마다 모든 받는 곳의 배포본을 담은 ZIP 하나를 받습니다.
- **제한**: 한 번에 파일 최대 100개. 받는 곳을 지정하면 파일 최대 10개, 받는 곳 최대 10곳.
- **크레딧**: Anti-AI로 파일당 1, 그리고 받는 곳마다 파일당 1. 이미지 2장을 3곳에 보내면 2 + 6 = 8 크레딧입니다.

<Warning>
  일부가 실패하면 성공한 건은 그대로 두고, Claude가 실패한 항목을 알려줍니다.
  실패한 파일이나 받는 곳만 다시 보내세요 — 요청 전체를 다시 보내면 성공한
  작업이 새로 만들어져 다시 차감됩니다.
</Warning>

## 계정·팀·개발자 설정

대화창에서 계정을 조회하고 관리할 수 있습니다.

| 항목            | 할 수 있는 일                                                                                 |
| --------------- | --------------------------------------------------------------------------------------------- |
| **사용량·플랜** | 플랜, 이번 주기 사용량과 남은 크레딧, 추가 크레딧, 크레딧 내역, 일·주·월별 사용량을 확인합니다. |
| **결제**        | 구독, 인보이스, 등록된 카드를 조회합니다. 조회만 가능합니다.                                  |
| **작업 기록**   | 지난 작업을 조회·검색하고, 작업 결과를 열고, 기록에서 작업을 삭제합니다.                       |
| **조직**        | 조직을 만들고 이름을 바꾸며, 멤버를 초대·제거하고, 멤버 역할을 바꾸고, 초대를 취소합니다.       |
| **API 키**      | 키 목록과 키별 사용량을 보고, 키를 발급하거나 비활성화합니다.                                  |
| **웹훅**        | 웹훅을 등록·수정·삭제하고, 전송 기록을 보고, 실패한 이벤트를 다시 보냅니다.                    |
| **조직 설정**   | 파일 보존 기간(7일 또는 30일)을 확인·변경하고, 활동 로그를 봅니다.                             |

- **관리자 전용**: 조직 변경, 조직의 API 키·웹훅 관리, 파일 보존 기간, 활동 로그는 그 조직의 소유자나 관리자 역할이 필요합니다.
- **한 번만 표시**: 새 API 키는 발급한 응답에서만 보입니다. 바로 저장하세요.
- **대시보드 전용**: 플랜 변경·해지, 크레딧 구매, 환불, 카드 등록·삭제, 조직 삭제·탈퇴, 초대 수락. 이런 작업은 Claude가 대시보드 링크를 안내합니다.
- **되돌릴 수 없음**: 작업 삭제, 멤버 제거, API 키 비활성화. Claude가 실행하기 전에 먼저 확인을 받습니다.

## Trace (파일럿)

<Note>
  Trace는 Trace 파일럿에 참여한 계정에서만 쓸 수 있습니다. Claude에게 "Trace
  쓸 수 있어?"라고 물어 내 계정을 확인하세요.
</Note>

Trace를 쓰면 ContentCare가 웹에서 내 콘텐츠의 사본을 찾아냅니다. 대화창에서 다음을 할 수 있습니다.

- **콘텐츠 등록**: Claude가 공식 사이트나 언어 같은 짧은 질문을 최대 3개 묻고, 추적을 위해 등록합니다.
- **원본 업로드**: 사본 대조 기준이 될 원본 이미지나 PDF(파일당 32MB까지)를 올립니다.
- **발견 사본 확인**: 기간, 국가, 받는 곳, 상태별로 확정된 사본을 조회하고 어떻게 퍼졌는지 봅니다.
- **리포트 보기**: ContentCare 팀이 발행한 기간 리포트를 엽니다.
- **대응 요청**: 선택한 사본에 대해 ContentCare 팀에 대응 준비를 요청합니다.

## 이렇게 물어보세요

`<이미지 주소>` 에 파일 링크를 넣으세요. Claude Code나 Codex CLI를 쓴다면 파일 경로를 넣어도 됩니다.


```text

<ZIP 파일 주소>
```

```text
이 이미지에 "고객사 A", "고객사 B" 워터마크 삽입해줘:
<이미지 주소>
```

## 청구 계정 설정

ContentCare에서 조직에 소속되어 있다면, 작업을 개인 계정으로도 조직 계정으로도 청구할 수 있습니다. 커넥터는 임의로 고르지 않고 **반드시 물어봅니다.**

계정 이름으로 답하면 작업이 진행됩니다. **한 번만 물어봅니다** — 선택한 계정을 기억해서 이후 작업에는 다시 묻지 않습니다. 다른 계정 이름을 말하면 그때 바뀝니다. 모든 결과에 어느 계정으로 청구됐는지 표시됩니다.

처음부터 지정해도 됩니다.

```text
이 이미지들에 Anti-AI 보호 적용해줘. 청구는 MORI Corp으로:
<이미지 주소 1>
<이미지 주소 2>
```

개인 계정 하나뿐이라면 묻지 않고 자동으로 사용합니다.
