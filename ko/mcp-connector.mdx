**BIZ MORI MCP 커넥터**를 쓰면 Claude 같은 AI 어시스턴트 안에서 바로 BIZ MORI를 사용할 수 있습니다. BIZ MORI 계정으로 한 번만 연결해두면, 이후에는 평소 말하듯 요청하면 됩니다.

<Note>
  **MCP**(Model Context Protocol)는 AI 어시스턴트를 외부 서비스와 연결하는 공개
  표준입니다. 사용하는 데 이 개념을 이해할 필요는 없습니다.
</Note>

## 청구 계정 설정

BIZ MORI에서 조직에 소속되어 있다면, 작업을 개인 계정으로도 조직 계정으로도 청구할 수 있습니다. 커넥터는 임의로 고르지 않고 **반드시 물어봅니다.**

계정 이름으로 답하면 작업이 진행됩니다. **한 번만 물어봅니다** — 선택한 계정을 기억해서 이후 작업에는 다시 묻지 않습니다. 다른 계정 이름을 말하면 그때 바뀝니다. 모든 결과에 어느 계정으로 청구됐는지 표시됩니다.

처음부터 지정해도 됩니다.

```text
이 이미지들에 Anti-AI 보호 적용해줘. 청구는 MORI Corp으로.
```

개인 계정 하나뿐이라면 묻지 않고 자동으로 사용합니다.

## 이미지 업로드 방식

**어떤 도구를 쓰느냐에 따라 가능한 이미지 업로드 방법이 다릅니다.**

|                                | 이미지 URL 링크 | 채팅에 이미지 직접 첨부 |
| ------------------------------ | :-------------: | :---------------------: |
| **Claude 앱** (웹 / 데스크톱)  |        ✓        |            X            |
| **Claude Code** (터미널 / IDE) |        ✓        |            ✓            |
| **Codex**                      |        ✓        |            ✓            |

<AccordionGroup>
  <Accordion title="Claude 앱 — 브라우저 업로드를 사용합니다" icon="browser">
    Claude 앱은 대화창에 첨부한 이미지를 MCP 커넥터에 직접 전달할 수 없습니다.
    이는 Claude 플랫폼의 제한이며 BIZ MORI에서 변경할 수 없습니다.

    대신 파일이 필요한 작업을 요청하면 Claude가 **BIZ MORI 업로드 페이지**를 제공합니다.

    ```text
    이 이미지가 AI 생성인지 검사해줘.
    ```

    브라우저에서 업로드를 완료한 뒤 대화창으로 돌아오면 Claude가 작업을 이어서 진행합니다.

    공개적으로 접근 가능한 이미지 URL이 이미 있다면 업로드 페이지 대신 URL을 바로 사용할 수도 있습니다.

    <Warning>
      이 과정은 Claude 앱에서만 필요합니다. Claude Code와 Codex는 로컬 파일을 직접 사용할 수 있습니다.
    </Warning>

  </Accordion>

  <Accordion title="Claude Code — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Claude Code는 컴퓨터의 파일을 직접 읽을 수 있습니다.

    ```text
    ~/Pictures/artwork.png 에 Anti-AI 보호 적용해줘
    ```

    별도의 업로드 페이지를 사용할 필요가 없습니다.

  </Accordion>

  <Accordion title="Codex — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Codex도 Claude Code와 동일하게 로컬 파일을 직접 사용할 수 있습니다.

    ```text
    ~/Pictures/artwork.png AI 생성인지 검사해줘
    ```

    별도의 업로드 페이지를 사용할 필요가 없습니다.

  </Accordion>
</AccordionGroup>

## 결과 받기

Claude가 작업이 끝날 때까지 기다렸다가 대화창으로 결과를 알려줍니다.

| 서비스            | 받는 결과                                              |
| ----------------- | ------------------------------------------------------ |
| **AI 검사**       | 확률과 판정 결과, 그리고 히트맵·오버레이·썸네일 이미지 |
| **워터마크 검출** | 검출된 워터마크 문구                                   |
| **Anti-AI**       | 보호 처리된 이미지의 다운로드 링크.                    |
| **워터마크 삽입** | 결과 ZIP의 다운로드 링크                               |

모든 결과에는 해당 작업을 [대시보드](https://app.bizmori.com)에서 열어보는 링크와, 어느 계정으로 청구됐는지가 함께 표시됩니다.

AI 검사는 세 가지 이미지를 기본으로 만듭니다. 추가 비용은 없습니다 — 이미지가 몇 장이든 검사 1회로 계산됩니다.

<Warning>
  **오래 걸리는 작업은 "처리 중" 상태로 돌아올 수 있습니다.** Claude는 약 2분까지만 기다리는데, 장수가 많은 Anti-AI나 무거운 워터마크 작업은 그보다 오래 걸릴 수 있습니다.

실패가 아니라 작업은 계속 진행 중입니다. 결과는 [대시보드](https://app.bizmori.com)에서 내려받거나, 몇 분 뒤 대화창으로 돌아와 Claude에게 해당 작업을 다시 확인해달라고 요청하세요.

</Warning>

<Note>
  다운로드 링크는 일정 시간이 지나면 만료됩니다. 링크가 열리지 않으면 Claude에게
  해당 작업의 새 링크를 받거나, 대시보드에서 내려받으세요.
</Note>

## 문제 해결

<AccordionGroup>
  <Accordion title='Claude 앱에서 첨부한 이미지를 읽을 수 없다고 나옵니다'>
    Claude 앱은 대화창에 첨부한 이미지를 MCP 커넥터에 직접 전달할 수 없습니다.
    오류가 아니라 Claude 플랫폼의 제한입니다.

    이미지 작업을 요청하면 Claude가 제공하는 **BIZ MORI 업로드 페이지**를 열어 파일을 업로드하세요.
    공개적으로 접근 가능한 이미지 URL이 있다면 URL을 바로 전달할 수도 있습니다.

    Claude Code와 Codex에서는 로컬 파일을 직접 사용할 수 있습니다.

  </Accordion>

<Accordion title='작업이 "처리 중"으로만 돌아오고 다운로드 링크가 없습니다'>
  Claude가 기다리는 시간을 넘긴 것으로, 장수가 많은 작업에서 생깁니다. 실패가
  아니라 계속 진행 중입니다. [대시보드](https://app.bizmori.com)에서 결과를
  내려받거나, 몇 분 뒤 Claude에게 그 작업을 다시 확인해달라고 하세요.
</Accordion>

<Accordion title='커넥터 기능이 보이지 않거나, Claude가 이상한 우회를 시도합니다'>
  **설정 → 커넥터**에서 연결을 끊었다가 다시 연결하세요. Claude가 기능 목록을
  캐싱하기 때문에 새로 추가된 기능은 재연결 후에 나타납니다. 그 전에는 여러 장을
  개별 작업으로 쪼개 보내거나 브라우저를 이용한 우회를 시도할 수 있습니다.
</Accordion>

<Accordion title='시작하자마자 사용량 한도에 걸립니다'>
  조직 계정이 아니라 개인 무료 계정으로 작업이 실행되고 있을 수 있습니다.
  Claude에게 사용 가능한 계정을 물어본 뒤, 작업할 때 조직 이름을 지정하세요.
</Accordion>

<Accordion title='다운로드 링크에서 오류가 납니다'>

  링크를 받거나, 대시보드에서 내려받으세요.
</Accordion>

  <Accordion title='그 밖의 문제'>
