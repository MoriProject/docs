**BIZ MORI MCP 커넥터**를 쓰면 Claude 같은 AI 어시스턴트 안에서 바로 BIZ MORI를 사용할 수 있습니다. BIZ MORI 계정으로 한 번만 연결해두면, 이후에는 평소 말하듯 요청하면 됩니다.

> "이 이미지가 AI로 생성된 건지 확인해줘: `<이미지 주소>`"

Claude가 BIZ MORI에서 작업을 실행하고 결과를 대화창에 알려줍니다. 코드도, API 키도, 대시보드도 필요 없습니다.

<Note>
  **MCP**(Model Context Protocol)는 AI 어시스턴트를 외부 서비스와 연결하는 공개
  표준입니다. 사용하는 데 이 개념을 이해할 필요는 없습니다.
</Note>

## 커넥터 연결하기

<Steps>
  <Step title="커넥터 설정 열기">
    Claude 앱(웹 또는 데스크톱)에서 **설정 → 커넥터 → 사용자 지정 커넥터 추가**로 이동합니다.
  </Step>
  <Step title="커넥터 URL 입력">
    ```
    https://mcp.bizmori.com/mcp
    ```

    이름은 알아보기 쉽게 `BIZ MORI` 정도로 지정하세요.

  </Step>
  <Step title="BIZ MORI 계정으로 로그인">
    BIZ MORI 로그인 창이 열립니다. [app.bizmori.com](https://app.bizmori.com)에서 쓰는 것과 같은 계정으로 로그인하고 연결을 승인하세요.

    <Check>
      API 키는 **필요하지 않습니다.**
    </Check>

  </Step>
  <Step title="요청해보기">
    새 대화를 열고 이렇게 입력해보세요.

    ```text
    BIZ MORI로 이 이미지가 AI 생성인지 확인해줘:
    <이미지 주소>
    ```

  </Step>
</Steps>

## 이미지 업로드 방식

**어떤 도구를 쓰느냐에 따라 가능한 이미지 업로드 방법이 다릅니다.**

|                                | 대화창에 첨부한 이미지 | 내 컴퓨터의 파일 | 이미지 주소(URL) |
| ------------------------------ | :--------------------: | :--------------: | :--------------: |
| **Claude 앱** (웹 / 데스크톱)  |           X            |        X         |        ✓         |
| **Claude Code** (터미널 / IDE) |           —            |        ✓         |        ✓         |
| **Codex**                      |           —            |        ✓         |        ✓         |

<AccordionGroup>
  <Accordion title="Claude 앱 — 반드시 이미지 주소를 써야 합니다" icon="browser">
    대화창에 **첨부한 이미지는 사용할 수 없습니다.** 첨부 파일은 Claude가 눈으로 보는 용도로만 들어가고, 커넥터에는 실제 파일이 전달되지 않습니다. BIZ MORI 쪽에서 해결할 수 없는 플랫폼 한계입니다. 앱은 내 컴퓨터의 파일에도 접근할 수 없습니다.

    따라서 이미지를 링크가 생기는 곳에 먼저 올리고 — Google Drive, Dropbox, Notion에서 링크 공유를 켜고 — 그 링크를 대화창에 붙여넣으세요.

    <Warning>
      사진을 첨부해놓고 Anti-AI 처리를 요청하면 동작하지 않습니다. Claude가 대신 링크를 달라고 요청할 것입니다.
    </Warning>

  </Accordion>
  <Accordion title="Claude Code — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Claude Code는 파일을 읽을 수 있으므로 이미지 위치만 알려주면 됩니다.

    ```text
    ~/Pictures/artwork.png 에 Anti-AI 보호 적용해줘
    ```

    파일 업로드까지 알아서 처리합니다. 이미지 주소를 써도 됩니다.

  </Accordion>
  <Accordion title="Codex CLI — 로컬 파일 업로드가 가능합니다" icon="terminal">
    Claude Code와 동일하게 파일 경로만 주면 업로드까지 처리합니다.
  </Accordion>
</AccordionGroup>

## 결과 받기

작업 시간에 따라 결과를 받는 방식이 달라집니다. Claude는 작업이 끝날 때까지 기다리지만, **약 2분까지만** 기다립니다.

| 서비스            | 소요 시간     | 결과를 받는 곳                                                                                    |
| ----------------- | ------------- | ------------------------------------------------------------------------------------------------- |
| **AI 검사**       | 빠름          | 대화창 — 확률과 판정이 바로 나옵니다. 요청했다면 히트맵 이미지도 함께.                            |
| **워터마크 검출** | 빠름          | 대화창 — 검출된 워터마크 문구가 바로 나옵니다.                                                    |
| **Anti-AI**       | 보통          | 대화창 — 보호 처리된 이미지의 다운로드 링크. 여러 장이면 ZIP 하나로 옵니다.                       |
| **워터마크 삽입** | **오래 걸림** | ⚠️ **대개 대화창에서 못 받습니다.** 완료 후 [대시보드](https://app.bizmori.com)에서 내려받으세요. |

<Warning>
  **워터마크 삽입은 대개 Claude가 기다리는 시간보다 오래 걸립니다.**
결과 파일은 이렇게 받으세요.

- **권장:** [대시보드](https://app.bizmori.com)에서 내려받기. 완료된 작업이 모두 여기 있습니다.
- 또는 몇 분 뒤 대화창으로 돌아와 Claude에게 그 작업을 다시 확인해달라고 하기.

Anti-AI도 장수가 많으면 같은 이유로 오래 걸릴 수 있습니다.

</Warning>

<Note>
  다운로드 링크는 일정 시간이 지나면 만료됩니다. 링크가 열리지 않으면 Claude에게
  해당 작업의 새 링크를 받거나, 대시보드에서 내려받으세요.
</Note>

## 이렇게 물어보세요

`<이미지 주소>` 에 이미지 링크를 넣으세요. Claude Code나 Codex CLI를 쓴다면 파일 경로를 넣어도 됩니다.

```text
이 이미지 AI 생성인지 검사하고 히트맵도 같이 만들어줘:
<이미지 주소>
```

```text
이 ZIP 안의 이미지 전부에 Anti-AI 보호를 high 강도로 적용해줘:
<ZIP 파일 주소>
```

```text
이 이미지에 "© 2026 MORI Corp" 워터마크 삽입해줘:
<이미지 주소>
```

```text
이 파일에 BIZ MORI 워터마크가 들어있어?
<이미지 주소>
```

```text
지난 일주일 BIZ MORI 작업 목록 보여주고, 실패한 게 있으면 알려줘.
```

## 청구 계정 설정

BIZ MORI에서 조직에 소속되어 있다면, 작업을 개인 계정으로도 조직 계정으로도 청구할 수 있습니다. 커넥터는 임의로 고르지 않고 **반드시 물어봅니다.**

계정 이름으로 답하면 작업이 진행됩니다. 처음부터 지정해도 됩니다.

```text
이 이미지들에 Anti-AI 보호 적용해줘. 청구는 MORI Corp으로:
<이미지 주소 1>
<이미지 주소 2>
```

개인 계정 하나뿐이라면 묻지 않고 자동으로 사용합니다.
