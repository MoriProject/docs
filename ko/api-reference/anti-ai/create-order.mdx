## 주문 결과 다운로드

주문이 `complete` 상태가 되면 [주문 결과 다운로드 URL 발급](/ko/api-reference/orders/download-order-v3)을 호출하세요. 한 번의 호출로 결과 파일별 URL(`files[]`)과 결과 전체 ZIP(`archiveUrl`)을 함께 받습니다.

```bash
curl -X GET https://api.bizmori.com/api/v3/orders/{orderId}/download \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
  URL은 최대 1시간 동안 유효하므로 다운로드할 때마다 새로 요청하세요. 파일은 주문의 `expiresAt`까지 내려받을 수 있으며, 그 뒤에는 `400 ORDER_EXPIRED`를 반환합니다. `sk_test_` 주문의 URL은 실제 결과가 아니라 고정 샘플 파일을 가리킵니다.
</Warning>
