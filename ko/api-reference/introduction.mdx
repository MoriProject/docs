## 기본 URL

```
https://api.bizmori.com
```

## 인증

모든 엔드포인트는 `Authorization` 헤더에 Bearer 형식으로 API 키 인증이 필요합니다:

```
Authorization: Bearer YOUR_API_TOKEN
```

자세한 내용은 [인증](/ko/authentication) 가이드를 참고하세요.

## 테스트 API 키

`sk_test_` 접두사의 테스트 API 키를 사용하면 Anti-AI, 워터마크, AI Detection 처리를 실행하지 않고 연동을 검증할 수 있습니다. 테스트 요청은 가상 응답을 반환하며 크레딧을 소모하지 않습니다.
