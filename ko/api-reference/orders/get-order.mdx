title: "주문 상세 조회"
openapi: "/ko/api-reference/openapi.yaml GET /api/v2/orders/{orderId}"
---

[`GET /api/v3/orders/{orderId}`](/ko/api-reference/orders/get-order-v3)로도 v3 API로 만든 워터마크 주문을 포함한 모든 주문을 조회할 수 있습니다. Anti-AI, AI Detection, v2 워터마크 주문은 이 엔드포인트와 같은 형식으로, v3 워터마크 주문은 결과 파일과 검출 결과를 포함해 반환합니다.
