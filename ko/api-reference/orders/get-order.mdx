<Warning>
  이 엔드포인트는 deprecated되었습니다. 모든 주문 종류를 한 가지 형식으로 반환하는 [주문 상세 조회(v3)](/ko/api-reference/orders/get-order-v3)를 사용하세요. 이 엔드포인트의 응답과 동작은 바뀌지 않습니다.
</Warning>

`sk_test_` 키를 사용하면 이 엔드포인트는 키의 계정이 소유한 테스트 주문만 반환합니다. 테스트 주문은 일반 주문과 같은 `pending`, `inProgress`, `complete`, `failed` 상태 값을 사용합니다.
