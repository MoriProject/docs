  **지원 종료 예정.** 이 v2 엔드포인트는 2026년 10월 9일 09:00 KST(00:00 UTC)에 지원 종료 예정입니다. 새로 연동한다면 [`POST /api/v3/orders/wtr-embed`](/ko/api-reference/watermark-embed/create-order-v3)를 사용하고, 마이그레이션 방법은 [워터마크 삽입 빠른 시작](/ko/quickstart/watermark-embed#v2에서-v3로-마이그레이션)을 참고하세요.

  **v2 지원 종료 후 동작** (2026년 10월 9일 09:00 KST, 00:00 UTC부터):

  - 인증·권한 검사는 지금처럼 먼저 수행하므로 `401`, `403` 오류는 기존과 같습니다.
  - 인증을 통과한 v2 워터마크 삽입·검출 요청은 live 키와 `sk_test_` 키 모두 `410 Gone`과 `{ "code": "WATERMARK_V2_API_SUNSET" }`을 받습니다. `Link` 헤더가 v3 엔드포인트를 가리키니 v3로 새로 요청하세요.
  - 그때까지 처리를 시작하지 않은 v2 주문은 처리되지 않고 실패로 확정됩니다. 주문 상세(`errors.errorCode`)와 실패 웹훅에 `WATERMARK_V2_API_SUNSET`과 v3 안내 메시지가 담기며, 과금되지 않고 크레딧은 복원됩니다.
  - 종료 시각에 이미 처리 중인 주문은 결과 기록까지 마칩니다. 이후 새로 다시 실행하지는 않습니다.
  - 기존 v2 주문 조회와 이미 생성된 결과·보고서 다운로드는 기존 보존 기간 안에서 계속 이용할 수 있습니다. v2 보고서를 새로 생성하거나 재생성할 수는 없습니다.

  그 전까지 요청·응답 동작은 같고, v2 워터마크 엔드포인트의 모든 응답에 `Deprecation: true`, `Sunset: Fri, 09 Oct 2026 00:00:00 GMT`, `Link` 헤더만 추가됩니다.
</Warning>

<Warning>
  **v3 워터마크 검출은 v2로 삽입한 워터마크를 검출할 수 없습니다.** 엔드포인트만 v3로 바꿔도 기존 v2 워터마크 이미지는 검출되지 않으며, v2 지원이 종료된 뒤 v2 검출을 위한 예외도 제공하지 않습니다.
</Warning>

## 지원 종료 후 응답

2026년 10월 9일 09:00 KST(00:00 UTC)부터 이 엔드포인트에 인증을 통과한 요청을 보내면 다음과 같이 응답합니다.

```http
HTTP/1.1 410 Gone
Content-Type: application/json; charset=utf-8
Deprecation: true
Sunset: Fri, 09 Oct 2026 00:00:00 GMT
Link: </api/v3/orders/wtr-embed>; rel="successor-version"

{ "code": "WATERMARK_V2_API_SUNSET" }
```

`Link` 헤더의 v3 엔드포인트로 새로 요청하세요.

<Note>
  `sk_test_` 키를 사용하면 응답의 BIZ MORI 테스트 업로드 URL로 파일을 업로드합니다. 업로드가 끝나면 confirm 없이 처리가 시작되며 다운로드 가능한 결과 파일은 만들지 않습니다.
</Note>

## 주문 결과 다운로드

주문이 `complete` 상태가 되면 [주문 결과 다운로드 URL 발급](/ko/api-reference/orders/download-order-v3)을 호출하세요. 한 번의 호출로 결과 파일별 URL(`files[]`)과 결과 전체 ZIP(`archiveUrl`)을 함께 받습니다.

```bash
curl -X GET https://api.bizmori.com/api/v3/orders/{orderId}/download \
  -H "Authorization: Bearer YOUR_API_KEY"
```

<Warning>
  URL은 최대 1시간 동안 유효하므로 다운로드할 때마다 새로 요청하세요. 파일은 주문의 `expiresAt`까지 내려받을 수 있으며, 그 뒤에는 `400 ORDER_EXPIRED`를 반환합니다. `sk_test_` 주문의 URL은 실제 결과가 아니라 고정 샘플 파일을 가리킵니다.
</Warning>
