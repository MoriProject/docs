  **v2 지원 종료 후 동작** (종료 예정: 2026년 10월 9일 09:00 KST, 00:00 UTC):

  - v2 워터마크 삽입·검출 신규 요청은 거절됩니다. v3로 새로 요청하세요.
  - 종료 전에 접수됐지만 처리를 시작하지 않은 v2 주문은 실패 처리됩니다. 크레딧은 복원되고, 구독한 웹훅으로 실패 알림이 전송됩니다.
  - 기존 v2 주문 조회와 이미 생성된 결과·보고서 다운로드는 기존 보존 기간 안에서 계속 이용할 수 있습니다. v2 보고서를 새로 생성하거나 재생성할 수는 없습니다.
</Warning>

<Warning>
  **v3 워터마크 검출은 v2로 삽입한 워터마크를 검출할 수 없습니다.** 엔드포인트만 v3로 바꿔도 기존 v2 워터마크 이미지는 검출되지 않으며, v2 지원이 종료된 뒤 v2 검출을 위한 예외도 제공하지 않습니다.
</Warning>

<Note>
  `sk_test_` 키를 사용하면 응답의 BIZ MORI 테스트 업로드 URL로 파일을 업로드합니다. 업로드가 끝나면 confirm 없이 처리가 시작되며 다운로드 가능한 결과 파일은 만들지 않습니다.
</Note>

## 주문 결과 다운로드

주문이 `complete` 상태가 되면 [다운로드 URL 발급](/ko/api-reference/orders/download-order) 엔드포인트를 사용하여 처리된 파일을 다운로드할 수 있습니다:

```bash
curl -X GET https://api.bizmori.com/api/v2/orders/{orderId}/download \
  -H "Authorization: Bearer YOUR_API_TOKEN"
```

<Warning>
  일반 주문 파일은 주문 생성 후 **최대 7일**까지 다운로드할 수 있습니다. `sk_test_` 주문은 결과 파일을 만들지 않으므로 다운로드 요청이 `404 PROCESSED_FILE_NOT_FOUND`를 반환합니다.
</Warning>
