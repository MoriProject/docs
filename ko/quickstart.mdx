## 사전 준비

모든 빠른 시작 가이드의 공통 요구사항:

- BIZ MORI API 키 ([여기서 발급](https://app.bizmori.com/keys))
- 이미지 파일 — `jpg`, `jpeg`, `png`, `webp`, `tiff`, `bmp`는 모든 서비스에서 지원됩니다. 비가시성 워터마크 삽입 또는 검출 서비스에서는 `pdf`도 추가로 지원됩니다.
