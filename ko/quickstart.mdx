## 사전 준비

모든 빠른 시작 가이드의 공통 요구사항:

- BIZ MORI API 키 ([여기서 발급](https://app.bizmori.com/keys))
- 이미지 파일 — `jpg`, `jpeg`, `png`, `webp`, `tiff`, `bmp`는 모든 서비스에서 지원됩니다. 비가시성 워터마크 삽입 또는 검출 서비스에서는 `pdf`도 추가로 지원됩니다.

## 프론트엔드인가요, 백엔드인가요?

둘 다입니다. 이 가이드의 모든 엔드포인트는 평범한 HTTPS와 JSON이고, 파일 전송은 presigned S3 URL로 이뤄집니다. 서버 전용 런타임이 필요한 부분이 없습니다. 주문 생성 → 업로드 → 상태 확인 → 다운로드 흐름은 Node.js 서비스에서든 브라우저의 React 컴포넌트에서든 똑같이 동작합니다.

각 빠른 시작 가이드에는 cURL, Node.js, Python 예제와 함께 단계마다 **React** 탭과 복사해서 바로 쓸 수 있는 전체 컴포넌트가 있습니다.
