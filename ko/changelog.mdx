안녕하세요, 팀 BIZ MORI입니다! 🙌

이번 1.1.0 업데이트에서는 **홈 대시보드를 새로 만들고, 좌측 메뉴 구조를 정리했으며, 온보딩과 각 기능 페이지의 사용성을 다듬었습니다.**

이제 플랜과 크레딧, 이번 달 사용량, 진행 중인 작업을 홈 한 화면에서 확인할 수 있습니다.

---

### 📊 홈에서 플랜, 사용량, 작업 상태를 한눈에 확인하세요

지금까지는 크레딧이 얼마나 남았는지, 이번 달에 얼마나 썼는지 보려면 구독 관리와 사용 기록 페이지를 오가야 했습니다.

이제 홈에 접속하면 아래 정보를 바로 볼 수 있습니다.

- **현재 플랜**: 플랜 이름, 갱신일, 사용 가능 크레딧(잔량/총량) 게이지. 구독 크레딧과 추가 구매 크레딧을 구분해 표시합니다.
- **이번 달 기능별 사용량**: AI 학습 방해 필터, 워터마크 삽입, 워터마크 검출, AI 생성 이미지 판별 4개 기능의 이번 달 처리 장수와 총 사용량.
- **서비스 사용량**: 일·주·월 단위로 크레딧 사용 추이를 차트로 보여줍니다. **전체 / WEB / API** 채널 필터로 대시보드 사용량과 API 사용량을 나눠 볼 수 있습니다.
- **작업 상태**: 현재 진행 중인 주문 수와 평균 처리 시간.
- **최근 사용 기록**: 최근 10건을 표로 보여줍니다. 행을 클릭하면 상세 화면으로 이동하고, 삭제·새로고침·전체 기록 보기를 바로 할 수 있습니다.
- **빠른 작업 시작**: Anti-AI, 워터마크, AI 생성 이미지 판별 페이지로 이동하는 바로가기.

평균 처리 시간은 선택한 기간에 완료된 주문이 없으면 `-`로 표시됩니다.

---

### 📋 상단 바를 없애고 메뉴를 왼쪽으로 모았어요

기존에는 요금제 버튼, 언어 설정, 프로필이 상단 바에 흩어져 있었고 고객 문의와 API 가이드는 좌측 메뉴에 따로 있었습니다.

이번 업데이트부터는 상단 바가 사라지고 콘텐츠 영역이 그만큼 넓어집니다. 흩어져 있던 항목은 좌측 메뉴 하단의 **프로필** 버튼 안으로 모았습니다.

- **프로필** 메뉴에서 언어 설정, 고객 문의, API 가이드, 개인정보 처리방침, 이용약관을 엽니다.
- 플랜 카드는 무료 플랜과 유료 플랜 모두 좌측 메뉴에 표시됩니다.
- 서비스 튜토리얼은 현재 작업을 유지할 수 있도록 새 창에서 열립니다.

---

### 🌄 워터마크 삽입과 검출을 별도 페이지로 나눴어요

지금까지는 워터마크 페이지 하나에서 탭을 전환해 삽입과 검출을 오가야 했습니다.

이제 좌측 메뉴에 **워터마크 삽입**과 **워터마크 검출** 메뉴가 각각 있습니다. 삽입 내역과 검출 내역도 서로 섞이지 않고 각 페이지에서 따로 관리합니다.

---

### 📋 처리 내역 테이블이 더 읽기 쉬워졌어요

Anti-AI(AI 학습 방해 필터), 워터마크 삽입, 워터마크 검출, AI 생성 이미지 판별 4개 페이지의 내역 테이블을 모두 개선했습니다.

- 총 건수를 표 상단에 표시합니다.
- Anti-AI와 워터마크 내역에는 원본 이미지 **미리보기 썸네일** 컬럼을 추가했습니다.
- 처리 내역이 없을 때는 빈 목록 대신 안내 화면을 보여줍니다.
- 페이지네이션 방식을 바꾸고, 이전·다음 버튼의 비활성 상태를 명확하게 표시합니다.
- 공백 없는 긴 파일명이 옆 컬럼을 넘어가지 않도록 줄바꿈합니다.
- AI 생성 이미지 판별 상세 화면의 버튼 이름을 **분석 보고서 다운로드**로 바꿨습니다.
- 사용 기록의 종류·채널·상태 필터 폭을 넓혀 영어·일본어 화면에서도 잘리지 않습니다.
