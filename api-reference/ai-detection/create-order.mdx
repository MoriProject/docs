## How to upload the image

After receiving the `uploadUrl` from the response, upload your image using a `PUT` request. Live keys return a presigned storage URL. Test keys return a ContentCare test upload URL that consumes and discards the request body:

```bash
curl -X PUT "UPLOAD_URL" \
  -H "Content-Type: image/jpeg" \
  --data-binary @photo.jpg
```

<Note>
  Live presigned upload URLs and test upload URLs both expire after **1 hour** and carry their own authorization, so do not add a Bearer header. With a live key, `fileKey` is the S3 object key; with a test key, it is an isolated logical key. If persistent test orders are disabled in your environment, a test key receives a mock response that is not stored, and its `test.invalid` `uploadUrl` cannot accept uploads. Upload the file before the URL expires, then call the [Confirm order](/api-reference/ai-detection/confirm-order) endpoint.
</Note>

## Getting the detection result

Once you confirm the upload, the order status changes to `inProgress`. When detection completes, the result is available via:

1. **Webhook** — Subscribe to `order.aiDetection.completed` or `order.aiDetection.failed` events
2. **Polling** — Call [Get order details](/api-reference/orders/get-order-v3) until `status` is `complete` or `failed`

When the order is `complete`, the detection result is in `result`. The example below omits the common order fields; see [Get order details](/api-reference/orders/get-order-v3) for the full response.

```json
{
  "data": {
    "type": "aiDetection",
    "orderId": "...",
    "status": "complete",
    "result": {
      "verdict": "likely_ai",
      "probability": 0.97,
      "options": {
        "generateHeatmap": true,
        "generateOverlay": false,
        "generateThumbnail": true
      },
      "originalImageUrl": "https://...",
      "heatmapUrl": "https://...",
      "overlayUrl": null
    }
  }
}
```

<Info>
  Test orders return deterministic detection results from the input file name. Use `_ai` for probability `0.98` or `_human` for probability `0.02`. Test orders do not create downloadable heatmap or overlay files.
</Info>

### Verdict

| `result.verdict` | Meaning |
|---|---|
| `likely_ai` | Likely AI-generated |
| `uncertain_ai` | Possibly AI-generated |
| `uncertain_real` | Possibly not AI-generated |
| `likely_real` | Likely not AI-generated |

The server determines the verdict from `result.probability`. A verdict expresses how likely the image is to be AI-generated. It does not confirm whether the image is AI-generated.
