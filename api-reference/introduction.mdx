## Base URL

```
https://api.bizmori.com
```

## Authentication

All endpoints require an API key passed via the `Authorization` header with Bearer format:

```
Authorization: Bearer YOUR_API_TOKEN
```

See the [Authentication](/authentication) guide for details.

## Test API keys

Use a test API key with the `sk_test_` prefix to validate the full order lifecycle without running Anti-AI, watermark, or AI Detection processing. Test orders can be retained for list, statistics, and detail checks, but they do not produce downloadable result files. See [Test API keys](/test-api-keys) for the upload and state-transition flow.
