**BIZ MORI API** は、デジタルコンテンツ保護サービスへのプログラマティックなアクセスを提供します。シンプルな REST API を通じて、画像を無断の AI 学習から保護し、目に見えない watermark を埋め込み、watermark の真正性を検証してください。

## ベース URL

```
https://api.bizmori.com
```

すべてのエンドポイントは **HTTPS** でのみ提供されます。HTTP リクエストはサポートされていません。

## リクエスト形式

`Content-Type: application/json` でリクエストを送信し、`Authorization` ヘッダーに API キーを含めます。

```
Authorization: Bearer YOUR_API_TOKEN
```

## レスポンス形式

すべてのレスポンスは JSON を返します。

**成功**
```json
{
  "data": { ... }
}
```

**エラー**
```json
{
  "code": "ERROR_CODE"
}
```

HTTP ステータスコードでエラーの種別を把握し、`code` フィールドでプログラム的な処理およびローカライゼーションを行ってください。全一覧は [エラーコード](/ja/errors) を参照してください。
