### 🔄 v3 の注文詳細・ダウンロードのレスポンスを 1 つの形式に統一しました（破壊的変更）

`GET /api/v3/orders/{orderId}` と `GET /api/v3/orders/{orderId}/download` は、Anti-AI、AI Detection、watermark 埋め込み、watermark 検出のすべての注文を、v2 と v3 のどちらで作成したかに関係なく 1 つの形式で返すようになりました。

**[注文詳細を取得（v3）](/ja/api-reference/orders/get-order-v3)**

- すべての注文が同じトップレベルのフィールドを返します: `type`、`orderId`、`orderName`、`channel`、`status`、`createdAt`、`updatedAt`、`expiresAt`、`retentionDays`、`thumbnailImageUrl`、`processingDelayed`、`errors`、`inputFiles`、`result`。
- 入力ファイルは `inputFiles[]` にあります。`role` は watermark 検出の注文にだけ、`uploadUrl` は注文が `pending` のときだけ含まれます。`fileCount` は廃止されたため、`inputFiles.length` を使用してください。
- `result` は `status` が `complete` のときだけオブジェクトで、それ以外は `null` です。Anti-AI と watermark 埋め込みの注文は `result.outputFiles[]`、watermark 検出の注文は `result.detectionStatus`、AI Detection の注文は `statusCode` の代わりに `result.verdict` を返します。
- `status` は `pending`、`inProgress`、`complete`、`failed`、`expired` の 5 つの値を使います。`detectionStatus` は `not_detected` の代わりに `undetected` を使います。
- すべての `fileId` は `"201"` のような数字の文字列です。`"601-1"` のような結果 ID は使われなくなりました。

**[注文結果のダウンロード URL を発行（v3）](/ja/api-reference/orders/download-order-v3)**

- レスポンスは `{ archiveUrl, files, expiresInSeconds }` です。結果全体の URL 1 つと、結果ファイルごとの URL をまとめて受け取れます。
- Anti-AI の注文と、v2 で作成した watermark 埋め込み注文にも対応しました。
- URL の有効期間は 300 秒から最大 1 時間に延びました。
- 処理が終わっていない注文は `400 ORDER_NOT_COMPLETED`、watermark 検出・AI Detection の注文は `400 ORDER_TYPE_CANT_DOWNLOAD` を返します。
- `GET /api/v3/orders/{orderId}/files/{fileId}/download` は削除されました。`files[]` を使用してください。

**非推奨（Deprecated）**

- `GET /api/v2/orders/{orderId}` と `GET /api/v2/orders/{orderId}/download` は非推奨になりました。レスポンスと動作は変わりません。

以前の v3 レスポンスを読み取っている場合は、新しいフィールドに更新してください。以前のフィールドと新しいフィールドの対応は、各 API ページにまとめています。

<Update label="1.1.0" description="2026-08-21">

こんにちは、BIZ MORI チームです！🙌

今回の 1.1.0 アップデートでは **ホームダッシュボードを新しく作成し、左側メニュー構成を整理し、オンボーディングと各機能ページの使いやすさを改善しました。**

これで、プランとクレジット、今月の利用量、進行中の作業をホーム画面ひとつで確認できます。

---

### 📊 ホームでプラン、利用量、作業ステータスを一目で確認できます

以前は、クレジットの残量や今月の利用量を確認するにはサブスクリプション管理と利用履歴ページを行き来する必要がありました。

今回から、ホームにアクセスすると以下の情報をすぐに確認できます。

- **現在のプラン**: プラン名、更新日、利用可能クレジット(残量/総量)ゲージ。サブスクリプションクレジットと追加購入クレジットを区別して表示します。
- **今月の機能別利用量**: AI学習妨害フィルター、watermark 埋め込み、watermark 検出、AI生成画像の判別の4機能の今月の処理枚数と総利用量。
- **サービス利用量**: 日・週・月単位でクレジット利用推移をチャートで表示します。**全体 / WEB / API** チャネルフィルターで、ダッシュボード利用量と API 利用量を分けて確認できます。
- **作業ステータス**: 現在進行中の注文数と平均処理時間。
- **最近の利用履歴**: 直近10件を表で表示します。行をクリックすると詳細画面に移動し、削除・再読み込み・全履歴表示をすぐに行えます。
- **クイックスタート**: Anti-AI、watermark、AI生成画像の判別ページへ移動するショートカット。

平均処理時間は、選択した期間内に完了した注文がない場合は `-` と表示されます。

---

### 📋 上部バーをなくし、メニューを左側にまとめました

以前は、料金プランボタン、言語設定、プロフィールが上部バーに散らばっており、お問い合わせと API ガイドは左側メニューに別々に置かれていました。

今回のアップデートから上部バーがなくなり、その分コンテンツ領域が広くなります。散らばっていた項目は、左側メニュー下部の**プロフィール**ボタンの中にまとめました。

- **プロフィール**メニューで言語設定、お問い合わせ、API ガイド、プライバシーポリシー、利用規約を開きます。
- プランカードは、無料プランと有料プランのどちらも左側メニューに表示されます。
- サービスチュートリアルは、現在の作業を維持できるように新しいウィンドウで開きます。

---

### 🌄 watermark 埋め込みと watermark 検出を別々のページに分けました

これまでは、watermark ページひとつでタブを切り替えて埋め込みと検出を行き来する必要がありました。

今回から、左側メニューに **watermark 埋め込み** と **watermark 検出** のメニューがそれぞれ用意されています。埋め込み履歴と検出履歴も互いに混ざることなく、各ページで個別に管理します。

---

### 📋 処理履歴テーブルがより見やすくなりました

Anti-AI(AI学習妨害フィルター)、watermark 埋め込み、watermark 検出、AI生成画像の判別の4ページの履歴テーブルをすべて改善しました。

- 総件数を表の上部に表示します。
- Anti-AI と watermark の履歴には、元画像の**プレビューサムネイル**列を追加しました。
- 処理履歴がない場合は、空のリストの代わりに案内画面を表示します。
- ページネーション方式を変更し、前へ・次へボタンの無効状態を明確に表示します。
- スペースのない長いファイル名が隣の列にはみ出さないよう改行します。
- AI生成画像の判別詳細画面のボタン名を**分析レポートをダウンロード**に変更しました。
- 利用履歴の種類・チャネル・ステータスフィルターの幅を広げ、英語・日本語の画面でも切れないようにしました。
