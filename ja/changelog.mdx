こんにちは、BIZ MORI チームです！🙌

今回の 1.1.0 アップデートでは **ホームダッシュボードを新しく作成し、左側メニュー構成を整理し、オンボーディングと各機能ページの使いやすさを改善しました。**

これで、プランとクレジット、今月の利用量、進行中の作業をホーム画面ひとつで確認できます。

---

### 📊 ホームでプラン、利用量、作業ステータスを一目で確認できます

以前は、クレジットの残量や今月の利用量を確認するにはサブスクリプション管理と利用履歴ページを行き来する必要がありました。

今回から、ホームにアクセスすると以下の情報をすぐに確認できます。

- **現在のプラン**: プラン名、更新日、利用可能クレジット(残量/総量)ゲージ。サブスクリプションクレジットと追加購入クレジットを区別して表示します。
- **今月の機能別利用量**: AI学習妨害フィルター、watermark 埋め込み、watermark 検出、AI生成画像の判別の4機能の今月の処理枚数と総利用量。
- **サービス利用量**: 日・週・月単位でクレジット利用推移をチャートで表示します。**全体 / WEB / API** チャネルフィルターで、ダッシュボード利用量と API 利用量を分けて確認できます。
- **作業ステータス**: 現在進行中の注文数と平均処理時間。
- **最近の利用履歴**: 直近10件を表で表示します。行をクリックすると詳細画面に移動し、削除・再読み込み・全履歴表示をすぐに行えます。
- **クイックスタート**: Anti-AI、watermark、AI生成画像の判別ページへ移動するショートカット。

平均処理時間は、選択した期間内に完了した注文がない場合は `-` と表示されます。

---

### 📋 上部バーをなくし、メニューを左側にまとめました

以前は、料金プランボタン、言語設定、プロフィールが上部バーに散らばっており、お問い合わせと API ガイドは左側メニューに別々に置かれていました。

今回のアップデートから上部バーがなくなり、その分コンテンツ領域が広くなります。散らばっていた項目は、左側メニュー下部の **プロフィール** ボタンひとつからすべて見つけられます。

- **プロフィール** メニューから、言語設定、お問い合わせ、API ガイド、プライバシーポリシー、利用規約を一か所で開けます。
- プランカードは、無料プランと有料プランのどちらも左側メニューに表示されます。
- サービスチュートリアルは、現在の作業を維持できるように新しいウィンドウで開きます。

---

### 🌄 watermark 埋め込みと watermark 検出を別々のページに分けました

これまでは、watermark ページひとつでタブを切り替えて埋め込みと検出を行き来する必要がありました。

今回から、左側メニューの **watermark 埋め込み** と **watermark 検出** に直接移動できます。埋め込み履歴と検出履歴もそれぞれのページで確認できるので、混同することがありません。

---

### 📋 処理履歴テーブルがより見やすくなりました

Anti-AI(AI学習妨害フィルター)、watermark 埋め込み、watermark 検出、AI生成画像の判別の4ページの処理履歴を一目で把握しやすく整えました。

- 表の上部で総件数をすぐに確認できます。
- Anti-AI と watermark の履歴では、元画像を **プレビューサムネイル** ですぐに確認できます。
- まだ処理履歴がない場合は、空のリストの代わりに次に何をすればよいかの案内画面が表示されます。
- ページを送るとき、前へ・次へボタンがこれ以上進めない状態かどうかがひと目でわかります。
- 長いファイル名も隣の列を隠さず、きれいに折り返されます。
- AI生成画像の判別の詳細画面では、**分析レポートをダウンロード** ボタンから判別結果のレポートをすぐに受け取れます。
- 利用履歴の種類・チャネル・ステータスフィルターが、英語・日本語の画面でも切れずに表示されます。

---

### 🎬 オンボーディング案内ページを改善しました

3. AI生成画像の判別
4. 組織の作成とメンバー招待
5. API キーと Webhook
