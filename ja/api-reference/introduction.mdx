## ベースURL

```
https://api.bizmori.com
```

## 認証

すべてのエンドポイントは、`Authorization` ヘッダーにBearer形式でAPIキー認証が必要です:

```
Authorization: Bearer YOUR_API_TOKEN
```

詳細は[認証](/ja/authentication)ガイドを参照してください。

## テストAPIキー

`sk_test_` プレフィックスのテストAPIキーを使用すると、Anti-AI、watermark、AI Detectionの処理を実行せずに連携を検証できます。テストリクエストは模擬レスポンスを返し、クレジットを消費しません。
