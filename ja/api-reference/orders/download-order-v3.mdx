完了した Anti-AI・watermark 埋め込み注文の結果をダウンロードするときに、このエンドポイントを使用します。1 回の呼び出しで、結果ファイルごとの URL と結果全体を受け取る URL をまとめて取得できます。watermark 注文を v2 と v3 のどちらで作成したかに関係なく、レスポンスの形式は同じです。

<Warning>
  2026 年 10 月 8 日にレスポンスの形式が変わり、`GET /api/v3/orders/{orderId}/files/{fileId}/download` は削除されました。[以前のレスポンスからの変更](#以前のレスポンスからの変更)を確認してください。
</Warning>

## レスポンスのフィールド

| フィールド | 型 | 説明 |
|------------|----|------|
| `archiveUrl` | string | 結果全体を受け取る URL。常にあります |
| `files[]` | array | 結果ファイルごとの `{ fileId, downloadUrl }` |
| `expiresInSeconds` | integer | URL の有効期間（秒）。最大 3600 |

`files[]` は、[注文詳細を取得](/ja/api-reference/orders/get-order-v3)の `result.outputFiles[]` と同じファイルを同じ順序で含み、`fileId` も同じです。`fileId` を使って、各 URL を結果ファイルとその `inputFileId` に対応付けてください。

### `archiveUrl` が指すファイル

| 注文 | `archiveUrl` |
|------|--------------|
| Anti-AI | すべての結果ファイルの ZIP |
| v2 で作成した watermark 埋め込み | すべての結果ファイルの ZIP |
| v3 で作成した watermark 埋め込み、結果ファイル 2 件以上 | すべての結果ファイルの ZIP |
| v3 で作成した watermark 埋め込み、結果ファイル 1 件 | その結果ファイル（`files[0].downloadUrl` と同じファイル） |

`archiveUrl` は結果ファイル 1 つか全体の ZIP のどちらかなので、1 つのダウンロードボタンにそのまま割り当てられます。

### URL の有効期間

URL は 3600 秒（1 時間）有効です。注文の保管期限（`expiresAt`）がそれより先に来る場合は残り時間に短縮し、短縮した値を `expiresInSeconds` に入れます。URL は保存せず、ダウンロードするたびにこのエンドポイントを呼び出してください。

## すべての結果ファイルをダウンロードする

<CodeGroup>
```javascript Node.js
import { writeFile } from 'node:fs/promises';

const headers = { Authorization: 'Bearer YOUR_API_KEY' };
const base = `https://api.bizmori.com/api/v3/orders/${orderId}`;

const { data: order } = await (await fetch(base, { headers })).json();
const { data: download } = await (await fetch(`${base}/download`, { headers })).json();

// files[] と result.outputFiles[] は fileId の値と順序が一致します。
const names = new Map(order.result.outputFiles.map((file) => [file.fileId, file.fileName]));
for (const { fileId, downloadUrl } of download.files) {
  const res = await fetch(downloadUrl);
  await writeFile(`${fileId}-${names.get(fileId)}`, Buffer.from(await res.arrayBuffer()));
}
```

```python Python
import requests

headers = {'Authorization': 'Bearer YOUR_API_KEY'}
base = f'https://api.bizmori.com/api/v3/orders/{order_id}'

order = requests.get(base, headers=headers).json()['data']
download = requests.get(f'{base}/download', headers=headers).json()['data']

# files[] と result.outputFiles[] は fileId の値と順序が一致します。
names = {f['fileId']: f['fileName'] for f in order['result']['outputFiles']}
for item in download['files']:
    res = requests.get(item['downloadUrl'])
    with open(f"{item['fileId']}-{names[item['fileId']]}", 'wb') as out:
        out.write(res.content)
```
</CodeGroup>

## エラー

次の順序でエラーを確認し、最初に該当したエラーを返します。

| 順序 | 条件 | HTTP | `code` |
|------|------|------|--------|
| 1 | 注文が存在しないか、他のアカウントの注文 | 404 | `ORDER_NOT_FOUND` |
| 2 | watermark 検出・AI Detection の注文（保管期限が過ぎていても同じ） | 400 | `ORDER_TYPE_CANT_DOWNLOAD` |
| 3 | 保管期限切れ | 400 | `ORDER_EXPIRED` |
| 3 | 保管期限を確認できない | 409 | `FILE_RETENTION_UNKNOWN` |
| 4 | `status` が `pending`、`inProgress`、`failed` | 400 | `ORDER_NOT_COMPLETED` |

`orderId` の形式が正しくない場合は `400 VALIDATION_FAILED` を返します。

## 以前のレスポンスからの変更

2026 年 10 月 8 日から、このエンドポイントは上記の形式で応答します。後方互換性のない変更です。

| 以前の動作 | 現在 |
|------------|------|
| レスポンス `{ downloadUrl, expiresInSeconds }` | `{ archiveUrl, files, expiresInSeconds }`。`downloadUrl` の代わりに `archiveUrl` |
| v3 の watermark 埋め込み注文のみ対応 | Anti-AI の注文と、v2・v3 で作成した watermark 埋め込み注文に対応 |
| URL は 300 秒有効 | 最大 3600 秒。保管期限までに制限 |
| 未完了の注文: `400 VALIDATION_FAILED` | `400 ORDER_NOT_COMPLETED` |
| watermark 検出・AI Detection の注文: 非対応 | 引き続き非対応で、専用のエラー `400 ORDER_TYPE_CANT_DOWNLOAD` を返す |
| 結果ファイルを 1 つ受け取る `GET /api/v3/orders/{orderId}/files/{fileId}/download` | 削除。このエンドポイントの `files[]` を使用 |

非推奨（deprecated）の [`GET /api/v2/orders/{orderId}/download`](/ja/api-reference/orders/download-order) は、以前のレスポンスをそのまま返します。

## テストキー

`sk_test_` キーで呼び出すと、同じキーで作成した完了済みの Anti-AI・watermark 埋め込みテスト注文で動作します。URL は処理結果ではなく、固定のサンプルファイルを指します。[テスト API キー](/ja/test-api-keys)を参照してください。
