---

**BIZ MORI MCP コネクタ**を使うと、Claude のような AI アシスタントの中から直接 BIZ MORI を利用できます。BIZ MORI アカウントで一度接続しておけば、あとは普段の会話のようにリクエストするだけです。

> 「この画像が AI で生成されたものか確認して: `<画像 URL>`」

Claude が BIZ MORI 上でジョブを実行し、結果をチャットで知らせてくれます。コードも、API キーも、ダッシュボードも必要ありません。

<Note>
  **MCP**（Model Context Protocol）は、AI アシスタントを外部サービスに接続する
  ためのオープンな標準規格です。使うにあたってこの概念を理解する必要はありません。
</Note>

## コネクタを接続する

<Steps>
  <Step title="コネクタの設定を開く">
    Claude アプリ（Web またはデスクトップ）で **設定 → コネクタ → カスタムコネクタを追加** に移動します。
  </Step>
  <Step title="コネクタの URL を入力する">
    ```
    https://mcp.bizmori.com/mcp
    ```

    名前はわかりやすく `BIZ MORI` のように設定してください。

  </Step>
  <Step title="BIZ MORI アカウントでログインする">
    BIZ MORI のログイン画面が開きます。[app.bizmori.com](https://app.bizmori.com)で使っているのと同じアカウントでログインし、接続を承認してください。

    <Check>
      API キーは **必要ありません。**
    </Check>

  </Step>
  <Step title="リクエストしてみる">
    新しいチャットを開いて、次のように入力してみましょう。

    ```text
    BIZ MORI でこの画像が AI 生成かどうか確認して:
    <画像 URL>
    ```

  </Step>
</Steps>

## 画像のアップロード方法

**使用するツールによって、利用できる画像アップロード方法が異なります。**

| | チャットに添付した画像 | 自分のPC上のファイル | 画像 URL |
| ------------------------------ | :---------------------: | :--------------------: | :-------: |
| **Claude アプリ**（Web / デスクトップ） | X | X | ✓ |
| **Claude Code**（ターミナル / IDE） | — | ✓ | ✓ |
| **Codex** | — | ✓ | ✓ |

<AccordionGroup>
  <Accordion title="Claude アプリ — 必ず画像 URL を使う必要があります" icon="browser">
    チャットに**添付した画像は使用できません。** 添付ファイルは Claude が「見る」ためだけに渡され、コネクタには実際のファイルが渡されません。これは BIZ MORI 側では解決できないプラットフォームの制約です。アプリは自分の PC 上のファイルにもアクセスできません。

    そのため、まず画像をリンクが生成される場所にアップロードし — Google Drive、Dropbox、Notion でリンク共有をオンにして — そのリンクをチャットに貼り付けてください。

    <Warning>
      写真を添付したまま Anti-AI 処理を依頼しても動作しません。Claude が代わりにリンクを求めてきます。
    </Warning>

  </Accordion>
  <Accordion title="Claude Code — ローカルファイルのアップロードが可能です" icon="terminal">
    Claude Code はファイルを読み取れるため、画像の場所を伝えるだけで済みます。

    ```text
    ~/Pictures/artwork.png に Anti-AI 保護を適用して
    ```

    ファイルのアップロードまで自動で処理します。画像 URL を使っても構いません。

  </Accordion>
  <Accordion title="Codex CLI — ローカルファイルのアップロードが可能です" icon="terminal">
    Claude Code と同様、ファイルパスを渡すだけでアップロードまで処理します。
  </Accordion>
</AccordionGroup>

## 結果を受け取る

Claude はジョブが完了するまで待ってから、結果をチャットで知らせます。

| サービス | 受け取る結果 |
| ----------------- | ---------------------------------------------------------------- |
| **AI 検査** | 確率と判定結果、そしてヒートマップ・オーバーレイ・サムネイル画像 |
| **watermark 抽出** | 検出された watermark の文言 |
| **Anti-AI** | 保護処理された画像のダウンロードリンク。複数枚の場合は1つの ZIP にまとまります |
| **watermark 埋め込み** | 結果 ZIP のダウンロードリンク |

すべての結果には、該当ジョブを[ダッシュボード](https://app.bizmori.com)で開くリンクと、どのアカウントに請求されたかが合わせて表示されます。

AI 検査はデフォルトで3種類の画像を生成します。追加料金はかかりません — 画像が何枚あっても検査1回として計算されます。

<Warning>
  **時間のかかるジョブは「処理中」の状態のまま返ってくることがあります。** Claude が待機するのは約2分までで、枚数の多い Anti-AI や重い watermark 処理はそれより長くかかることがあります。

  失敗ではなく、ジョブは引き続き実行中です。結果は次の方法で受け取ってください。

  - [ダッシュボード](https://app.bizmori.com)からダウンロードする。完了したジョブはすべてここにあります。
  - または数分後にチャットに戻り、Claude にそのジョブをもう一度確認してもらう。
</Warning>

<Note>
  ダウンロードリンクは一定時間が経過すると期限切れになります。リンクが開けない
  場合は、Claude に該当ジョブの新しいリンクをもらうか、ダッシュボードからダウン
  ロードしてください。
</Note>

## こう聞いてみましょう

`<画像 URL>` に画像のリンクを入れてください。Claude Code や Codex CLI を使っている場合は、ファイルパスを入れても構いません。

```text
この画像が AI 生成かどうか検査して:
<画像 URL>
```

```text
この ZIP 内の画像すべてに Anti-AI 保護を high 強度で適用して:
<ZIP ファイル URL>
```

```text
この画像に「© 2026 MORI Corp」watermark を埋め込んで:
<画像 URL>
```

```text
このファイルに BIZ MORI watermark が入っている?
<画像 URL>
```

```text
先週の BIZ MORI 作業一覧を見せて、失敗したものがあれば教えて。
```

## 請求先アカウントの設定

BIZ MORI で組織に所属している場合、ジョブを個人アカウントにも組織アカウントにも請求できます。コネクタは勝手に選ばず、**必ず確認します。**

アカウント名で答えるとジョブが実行されます。**確認は一度だけです** — 選択したアカウントを記憶し、以降のジョブでは再度尋ねません。別のアカウント名を伝えれば、そこで切り替わります。すべての結果に、どのアカウントに請求されたかが表示されます。

最初から指定しても構いません。

```text
これらの画像に Anti-AI 保護を適用して。請求は MORI Corp で:
<画像 URL 1>
<画像 URL 2>
```

個人アカウントしかない場合は、確認せず自動的に使用されます。
