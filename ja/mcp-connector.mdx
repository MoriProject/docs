description: 'コードも API キーも使わず、Claude との会話だけで ContentCare を使う'
---

**ContentCare MCP コネクタ**を使うと、Claude のような AI アシスタントの中から直接 ContentCare を利用できます。ContentCare アカウントで一度接続しておけば、あとは普段の会話のようにリクエストするだけです。

> 「この画像が AI で生成されたものか確認して: `<画像 URL>`」

Claude が ContentCare 上でジョブを実行し、結果をチャットで知らせてくれます。コードも、API キーも、ダッシュボードも必要ありません。

<Note>
  **MCP**（Model Context Protocol）は、AI アシスタントを外部サービスに接続する
  ためのオープンな標準規格です。使うにあたってこの概念を理解する必要はありません。
</Note>

## コネクタを接続する

<Tabs>
  <Tab title="Claude アプリ">
    <Steps>
      <Step title="コネクタの設定を開く">
        Claude アプリ（Web またはデスクトップ）で **設定 → コネクタ → カスタムコネクタを追加** に移動します。
      </Step>
      <Step title="コネクタの URL を入力する">
        ```
        https://mcp.contentcare.ai/mcp
        ```

        名前はわかりやすく `ContentCare` のように設定してください。

      </Step>
      <Step title="ContentCare アカウントでログインする">
        ContentCare のログイン画面が開きます。[app.contentcare.ai](https://app.contentcare.ai)で使っているのと同じアカウントでログインし、接続を承認してください。

        <Check>
          API キーは **必要ありません。**
        </Check>

      </Step>
      <Step title="リクエストしてみる">
        新しいチャットを開いて、次のように入力してみましょう。

        ```text
        ContentCare でこの画像が AI 生成かどうか確認して:
        <画像 URL>
        ```

      </Step>
    </Steps>

  </Tab>
  <Tab title="Claude Code">
    ターミナルからコネクタを追加します。

    ```bash
    claude mcp add --transport http contentcare https://mcp.contentcare.ai/mcp
    ```

    次に Claude Code で `/mcp` を実行して `contentcare` を選び、開いたブラウザ画面で ContentCare アカウントにログインしてください。

  </Tab>
  <Tab title="Codex CLI">
    コネクタを追加してログインします。

    ```bash
    codex mcp add contentcare --url https://mcp.contentcare.ai/mcp
    codex mcp login contentcare
    ```

    ブラウザ画面が開いたら、ContentCare アカウントでログインし、接続を承認してください。

  </Tab>
</Tabs>

<Note>
  以前に `https://mcp.bizmori.com/mcp` でコネクタを追加した場合は、削除してから
  上記の新しい URL で追加し直してください。
</Note>

## ファイルのアップロード方法

**使用するツールによって、利用できるファイルアップロード方法が異なります。**

| | チャットに添付したファイル | 自分のPC上のファイル | ファイル URL |
| ------------------------------ | :---------------------: | :--------------------: | :-------: |
| **Claude アプリ**（Web / デスクトップ） | X | ✓（アップロード画面） | ✓ |
| **Claude Code**（ターミナル / IDE） | — | ✓ | ✓ |
| **Codex** | — | ✓ | ✓ |

<AccordionGroup>
  <Accordion title="Claude アプリ — アップロード画面かファイル URL を使ってください" icon="browser">
    チャットに**添付したファイルは使用できません。** 添付ファイルは Claude が「見る」ためだけに渡され、コネクタには実際のファイルが渡されません。これは ContentCare 側では解決できないプラットフォームの制約です。

    代わりに、Claude にアップロード画面を開くよう頼んでください。

    ```text
    AI 生成かどうか検査する画像をアップロードしたいので、ContentCare のアップロード画面を開いて。
    ```

    チャット内にアップロード画面が表示されます。ファイルをドラッグすると、同じ画面に結果が表示されます。画面が表示されない場合は、Claude が代わりに10分間有効な使い捨てのアップロードリンクを渡します。

    アップロード画面は一度にファイルを1つ受け付けます。watermark 抽出のみ、原本と検査するファイルの2つを受け付けます。複数枚をまとめて処理するには、リンクが生成される場所 — リンク共有をオンにした Google Drive、Dropbox、Notion — にアップロードし、各リンクまたは ZIP のリンクをチャットに貼り付けてください。

  </Accordion>
  <Accordion title="Claude Code — ローカルファイルのアップロードが可能です" icon="terminal">
    Claude Code はファイルを読み取れるため、ファイルの場所を伝えるだけで済みます。

    ```text
    ~/Pictures/artwork.png に Anti-AI 保護を適用して
    ```

    ファイルのアップロードまで自動で処理します。ファイル URL を使っても構いません。

  </Accordion>
  <Accordion title="Codex CLI — ローカルファイルのアップロードが可能です" icon="terminal">
    Claude Code と同様、ファイルパスを渡すだけでアップロードまで処理します。
  </Accordion>
</AccordionGroup>

## 結果を受け取る

Claude はジョブが完了するまで待ってから、結果をチャットで知らせます。

| サービス | 受け取る結果 |
| ----------------- | ---------------------------------------------------------------- |
| **AI 検査** | 確率と判定結果、そしてヒートマップ・オーバーレイ・サムネイル画像 |
| **watermark 抽出** | 自分の watermark が検出されたかどうかと、自分で埋め込んだ watermark であればその文言 |
| **Anti-AI** | 保護処理された画像のダウンロードリンク。複数枚の場合は1つの ZIP にまとまります |
| **watermark 埋め込み** | watermark の文言ごとに結果ファイル1つ。複数ある場合は1つの ZIP とファイルごとのリンクが届きます |

すべての結果には、該当ジョブを[ダッシュボード](https://app.contentcare.ai)で開くリンクと、どのアカウントに請求されたかが合わせて表示されます。

AI 検査はデフォルトで3種類の画像を生成します。追加料金はかかりません — 画像が何枚あっても検査1回として計算されます。watermark 埋め込みは文言1つにつき1回として計算されます。

<Warning>
  **時間のかかるジョブは「処理中」の状態のまま返ってくることがあります。** Claude が待機するのは約2分までで、枚数の多い Anti-AI や重い watermark 処理はそれより長くかかることがあります。

  失敗ではなく、ジョブは引き続き実行中です。結果は次の方法で受け取ってください。

  - [ダッシュボード](https://app.contentcare.ai)からダウンロードする。完了したジョブはすべてここにあります。
  - または数分後にチャットに戻り、Claude にそのジョブをもう一度確認してもらう。
</Warning>

<Note>
  ダウンロードリンクは一定時間が経過すると期限切れになります。リンクが開けない
  場合は、Claude に該当ジョブの新しいリンクをもらうか、ダッシュボードからダウン
  ロードしてください。
</Note>

### watermark 抽出には原本が必要です

ContentCare は、検査するファイルを watermark を埋め込んだ原本ファイルと比較して watermark を見つけます。**Claude には必ず両方のファイルを渡してください。**

結果は次のいずれかです。

| 結果 | 意味 |
| ------------ | ------------------------------------------------------------------------ |
| **検出** | watermark が見つかりました。自分のアカウントで埋め込んだものであれば文言が表示されます。 |
| **未検出** | watermark は見つかりませんでした。 |
| **判定不能** | watermark の候補はありますが、確信できるほどではありません。 |
| **処理不可** | ファイルを処理できませんでした。利用量は復元されます。 |
| **エラー** | 検査に失敗しました。watermark がないという意味ではありません。利用量は復元されます。 |

埋め込みと抽出は別々のジョブです。Claude は埋め込みを確認するために自分から抽出を実行しないため、二重に差し引かれることはありません。

### 分析レポート

watermark 抽出や AI 検査のジョブが完了したら、Claude にそのジョブの PDF レポートを依頼してください。

```text
さっきのジョブの分析レポートを日本語で作って。
```

レポートは日本語、英語、韓国語で受け取れます。PDF ファイルに対するレポートは韓国語のみです。レポートのリンクは5分で期限切れになるため、必要に応じて Claude に新しいリンクを依頼してください。

## 保護してエクスポート

保護してエクスポートは、Anti-AI と送付先ごとの watermark を一度に適用します。送付先の名前がそのまま watermark の文言になります。後でコピーが流出した場合は、そのコピーで watermark 抽出を実行してください。検出された文言から、どの送付先の配布版かがわかります。

```text
これらの画像を保護して、スタジオ A、スタジオ B、スタジオ C 向けにそれぞれエクスポートして:
<画像 URL 1>
<画像 URL 2>
```

- **まとめ方**: デフォルトでは送付先ごとにファイル1つです。ZIP を指定すると、画像ごとにすべての送付先の配布版を入れた ZIP を1つ受け取ります。
- **制限**: 1回につきファイル最大100個。送付先を指定する場合は、ファイル最大10個、送付先最大10件。
- **クレジット**: Anti-AI でファイル1つにつき1、さらに送付先ごとにファイル1つにつき1。画像2枚を3件の送付先に送ると 2 + 6 = 8 クレジットです。

<Warning>
  一部が失敗した場合、成功したものはそのまま残り、Claude が失敗した項目を
  知らせます。失敗したファイルや送付先だけを再送してください — リクエスト全体
  を再送すると、成功したジョブが新たに作られて再度差し引かれます。
</Warning>

## アカウント・チーム・開発者設定

チャットでアカウントを照会・管理できます。

| 項目 | できること |
| --------------- | --------------------------------------------------------------------------------------------- |
| **利用状況・プラン** | プラン、今回の請求期間の利用量と残りクレジット、追加クレジット、クレジット履歴、日・週・月ごとの利用量を確認します。 |
| **お支払い** | サブスクリプション、請求書、登録済みカードを照会します。照会のみ可能です。 |
| **作業履歴** | 過去の作業を照会・検索し、作業結果を開き、履歴から作業を削除します。 |
| **組織** | 組織を作成して名前を変更し、メンバーの招待・削除、メンバーの役割変更、招待の取り消しを行います。 |
| **API キー** | キー一覧とキーごとの利用量を確認し、キーを発行または無効化します。 |
| **Webhook** | Webhook の登録・更新・削除、送信履歴の確認、失敗したイベントの再送を行います。 |
| **組織設定** | ファイル保存期間（7日または30日）の確認・変更と、アクティビティログの確認を行います。 |

- **管理者のみ**: 組織の変更、組織の API キー・Webhook の管理、ファイル保存期間、アクティビティログには、その組織のオーナーまたは管理者の役割が必要です。
- **一度だけ表示**: 新しい API キーは発行時の応答にのみ表示されます。すぐに保存してください。
- **ダッシュボードのみ**: プランの変更・解約、クレジットの購入、返金、カードの登録・削除、組織の削除・脱退、招待の承諾。これらは Claude がダッシュボードのリンクを案内します。
- **元に戻せない操作**: 作業の削除、メンバーの削除、API キーの無効化。Claude は実行する前に確認を求めます。

## Trace（パイロット）

<Note>
  Trace は Trace パイロットに参加しているアカウントでのみ利用できます。Claude に
  「Trace は使える?」と尋ねて、自分のアカウントを確認してください。
</Note>

Trace を使うと、ContentCare が Web 上で自分のコンテンツのコピーを見つけ出します。チャットから次のことができます。

- **コンテンツの登録**: Claude が公式サイトや言語などの短い質問を最大3つ尋ね、追跡のために登録します。
- **原本のアップロード**: コピーの照合基準となる原本の画像や PDF（ファイルあたり32MBまで）をアップロードします。
- **発見されたコピーの確認**: 期間、国、送付先、状態ごとに確定したコピーを照会し、どのように広がったかを確認します。
- **レポートの閲覧**: ContentCare チームが発行した期間レポートを開きます。
- **対応の依頼**: 選択したコピーについて、ContentCare チームに対応の準備を依頼します。

## 請求先アカウントの設定

ContentCare で組織に所属している場合、ジョブを個人アカウントにも組織アカウントにも請求できます。コネクタは勝手に選ばず、**必ず確認します。**

アカウント名で答えるとジョブが実行されます。**確認は一度だけです** — 選択したアカウントを記憶し、以降のジョブでは再度尋ねません。別のアカウント名を伝えれば、そこで切り替わります。すべての結果に、どのアカウントに請求されたかが表示されます。

最初から指定しても構いません。

```text
これらの画像に Anti-AI 保護を適用して。請求は MORI Corp で:
<画像 URL 1>
<画像 URL 2>
```

個人アカウントしかない場合は、確認せず自動的に使用されます。
