**The BIZ MORI MCP Connector** lets you use BIZ MORI directly inside AI assistants like Claude. Connect your BIZ MORI account once, then simply ask for what you need in natural language.

<Note>
  **MCP (Model Context Protocol)** is an open standard for connecting AI
  assistants to external services. You don't need to understand it to use the
  connector.
</Note>

## Connect the connector

<AccordionGroup>
  <Accordion title="Claude App (Web / Desktop)" icon="sparkles">
    <Steps>
      <Step title="Open Connector Settings">
        Go to **Settings → Connectors → Add custom connector**.
      </Step>

      <Step title="Enter the connector URL">
        ```text
        https://mcp.bizmori.com/mcp
        ```

        You can name it something like `BIZ MORI`.
      </Step>

      <Step title="Sign in with your BIZ MORI account">
        A BIZ MORI sign-in window will appear.

        Sign in using the same account you use at [app.bizmori.com](https://app.bizmori.com) and approve the connection.

        <Check>
          No API key is required.
        </Check>
      </Step>

      <Step title="Start using BIZ MORI">
        Open a new conversation and start using BIZ MORI features.

        If a job requires a file upload, Claude will automatically provide a **BIZ MORI upload page**.
      </Step>
    </Steps>

  </Accordion>

  <Accordion title="Claude Code / Codex" icon="terminal">
    Claude Code and Codex both support the BIZ MORI MCP server.

    Add the following MCP server to your tool's MCP configuration.

    ```text
    https://mcp.bizmori.com/mcp
    ```

    When prompted, sign in with your BIZ MORI account and approve the connection.

    <Check>
      No API key is required.
    </Check>

    Once connected, you can use local files directly.

    ```text
    Check whether ~/Pictures/artwork.png was AI-generated.
    ```

  </Accordion>
</AccordionGroup>
## Billing account

If you're a member of an organization in BIZ MORI, you can bill jobs to either your personal account or your organization. The connector **always asks first** instead of choosing automatically.

Reply with the account name and the job will continue.

It only asks **once**—your choice is remembered for future jobs. If you later specify another account, the connector switches to that account. Every result also shows which account was billed.

You can specify the account up front.

```text
Apply Anti-AI protection to these images. Bill MORI Corp.
```

If you only have a personal account, it will be used automatically.

## Image upload

**Available upload methods depend on which AI tool you're using.**

|                              | Image URL | Attach image directly in chat |
| ---------------------------- | :-------: | :---------------------------: |
| **Claude App** (Web/Desktop) |     ✓     |               X               |
| **Claude Code**              |     ✓     |               ✓               |
| **Codex**                    |     ✓     |               ✓               |

<AccordionGroup>
  <Accordion title="Claude App — Browser upload" icon="browser">
    The Claude app cannot pass images attached in chat directly to MCP connectors.
    This is a limitation of the Claude platform and cannot be changed by BIZ MORI.

    Instead, whenever a job requires a file, Claude provides a **BIZ MORI upload page**.

    ```text
    Check whether this image was AI-generated.
    ```

    Upload your file in the browser, then return to the conversation. Claude will automatically continue the job.

    If your image is already available through a public URL, you can simply provide the URL instead.

    <Warning>
      This process is only required in the Claude app. Claude Code and Codex can use local files directly.
    </Warning>

  </Accordion>

  <Accordion title="Claude Code — Local files supported" icon="terminal">
    Claude Code can access files directly from your computer.

    ```text
    Apply Anti-AI protection to ~/Pictures/artwork.png
    ```

    No browser upload page is required.

  </Accordion>

  <Accordion title="Codex — Local files supported" icon="terminal">
    Codex also supports local files directly.

    ```text
    Check whether ~/Pictures/artwork.png was AI-generated.
    ```

    No browser upload page is required.

  </Accordion>
</AccordionGroup>

## Results

Claude waits for the job to finish and then returns the results in the conversation.

| Service                  | Result                                                       |
| ------------------------ | ------------------------------------------------------------ |
| **AI Detection**         | Probability, verdict, heatmap, overlay, and thumbnail images |
| **Watermark Extraction** | Extracted watermark text                                     |
| **Anti-AI**              | Download link for the protected image                        |
| **Watermark Embedding**  | Download link for the output ZIP                             |

Every result includes a link to open the job in the [Dashboard](https://app.bizmori.com) along with the billing account used.

AI Detection always generates a heatmap, overlay, and thumbnail. There is no additional cost—one image detection counts as one job regardless of these outputs.

<Warning>
  **Long-running jobs may return as "Processing".** Claude waits for approximately two minutes. Large Anti-AI or watermark jobs may take longer.

This does **not** mean the job failed. The job is still running.

You can download the completed result later from the [Dashboard](https://app.bizmori.com), or simply ask Claude to check the job again after a few minutes.

</Warning>

<Note>
  Download links expire after a period of time. If a link no longer works, ask
  Claude for a new download link or download the result from the Dashboard.
</Note>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Claude App can't read my attached image">
    The Claude app cannot pass images attached in chat directly to MCP connectors.
    This is a Claude platform limitation, not an error.

    When you request an image-based job, Claude provides a **BIZ MORI upload page** where you can upload the file.

    If your image already has a public URL, you can simply provide that URL instead.

    Claude Code and Codex can use local files directly.

  </Accordion>

  <Accordion title='My job stays in "Processing" and no download link appears'>
    Claude reached its waiting limit. This commonly happens with large jobs.

    The job is still running. Download the completed result from the [Dashboard](https://app.bizmori.com) or ask Claude to check the job again a few minutes later.

  </Accordion>

  <Accordion title='The connector is missing features or Claude behaves strangely'>
    Disconnect and reconnect the connector from **Settings → Connectors**.

    Claude caches available tools, so newly added features appear only after reconnecting.

  </Accordion>

  <Accordion title='I immediately hit my usage limit'>
    Your jobs may be running under your personal account instead of your organization.

    Ask Claude which billing accounts are available and specify your organization when starting the job.

  </Accordion>

  <Accordion title='The download link no longer works'>
    Download links expire.

    Ask Claude for a new download link or download the result directly from the Dashboard.

  </Accordion>

  <Accordion title='Other issues'>
    Contact us at [support@bizmori.com](mailto:support@bizmori.com).
  </Accordion>
</AccordionGroup>
